# Ocean2
# 🌊 Marine AI - 부산 해양정보 웹앱

부산 연안 어민을 위한 실시간 해양 정보 분석 웹앱입니다.

기상 데이터와 해양 환경 데이터를 기반으로 현재 조업 환경을 분석하고,
AI 기반 어종 추천 및 위험도 분석을 제공하는 것을 목표로 합니다.

---

# 📌 주요 기능

## 1. 실시간 해양 정보 제공

사용자가 현재 해역의 상태를 빠르게 확인할 수 있도록 다음 정보를 제공합니다.

- 수온
- 풍속
- 파고
- 염분
- 기온
- 날씨 정보

향후 공식 Open API 연동을 통해 실시간 데이터로 운영 가능합니다.

---

# 2. 부산 해역 지도

Leaflet.js 기반 지도 시스템을 사용합니다.

제공 기능:

- 부산 연안 지도 표시
- 주요 항구 위치 표시
- 현재 GPS 위치 표시
- 해역별 정보 확인


지원 예정 항구:

- 감천항
- 다대포
- 기장
- 송정

---

# 3. AI 어종 추천 시스템

현재 해양 환경 데이터를 분석하여
조업 가능성이 높은 어종을 추천합니다.

분석 요소:

- 수온
- 파고
- 풍속
- 계절
- 해양 환경
